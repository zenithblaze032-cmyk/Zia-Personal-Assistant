=============================================================
             ZIA ASSISTANT - COMPREHENSIVE COMMAND GUIDE
=============================================================
This file lists every voice command implemented in Zia.py + skills/*
+ core/tools.py + core/executor.py (AgentNova).

Notes:
- Wake-word gated. Default WAKE_WORD is "wake up" with aliases below.
  Say wake word first when ASLEEP, then your command. Inline works:
  "wake up Zia, what time is it".
- After waking, Zia stays AWAKE until IDLE_TIMEOUT_S (default 90s),
  then auto-sleeps. Say "go to sleep" to force sleep.
- Priority (first match wins): workspace > routines > web > system >
  media > apps > notes > weather > timers > clipboard >
  window_manager > automation. Unmatched -> Brain -> SIMPLE (LLM
  answer) or TOOL/MULTI_STEP (AgentNova).
- Say "abort task" to cancel stuck web search / fetch / AgentNova.

-------------------------------------------------------------
1. WAKE / SLEEP / EXIT / INTERRUPT (core/config.py + Zia.py)
-------------------------------------------------------------
WAKE_WORD (default): "wake up"
WAKE_WORD_ALIASES: zia, hey zia, hi zia, ok zia, jarvis, hey jarvis,
  hi jarvis, ok jarvis, jervis, jarves, arise, okiro, okiru, wake-up,
  wakeup, wake up zia, wake up jarvis, ziya, zeah, zea, c-ya, see ya,
  see-ya, tsia, xea, zee ah, ziaa, ziaah, sia, siya, seah, sea, see-ah,
  see ah, seea, siaa, jia, jiya, jeah, jea, jee-ah, jee ah, jeea, jiaa

  * "Zia" / "hey Zia" / "wake up" -> wakes ASLEEP -> AWAKE.
    She says Zia_WAKE_PHRASE ("Welcome back sir, how can I help you?").
  * Inline: "wake up Zia, open notepad" -> wakes + runs remainder.

SLEEP_PHRASES (substring match):
  * "go to sleep" / "sleep Zia" / "Zia sleep" / "standby" / "sleep"
    -> standby ASLEEP + memory consolidation.

EXIT_PHRASES (substring match, os._exit(0)):
  * "exit Zia" / "quit Zia" / "shut down Zia" / "shutdown Zia" /
    "close Zia" / "shut down" / "shutdown"

BARGE-IN WHILE SPEAKING (core/asr.py INTERRUPT_PHRASES):
  * "shut up" / "stop talking" / "quiet" / "abort" / "cancel" / "enough"
    -> interrupts TTS at once. If text also has "sleep", goes to sleep.

ABORT BACKGROUND TASK (skills/system.py, task_abort_event):
  * "abort task" / "stop task" / "stop what you are doing" / "cancel task"
    -> cancels DDGS search, Playwright fetch, AgentNova loop.

6. APP & WEBSITE LAUNCHER (skills/apps.py)
-------------------------------------------------------------
Pattern: [can you|please|hey|go ahead and] + open|launch|start|run
  [up] + [the|a|an] + <target>
  e.g. "open notepad", "launch chrome", "please open youtube",
  "can you open spotify", "start calculator", "run file explorer"

Chain: phonetic-alias normalize -> exact site -> exact app ->
  substring site/app -> fuzzy difflib (60pct) -> bare domain
  (foo.com) -> Windows `start` fallback + Start-menu type+Enter.

APPS: notepad, calculator/calc, paint, cmd/command prompt,
  terminal/windows terminal, file explorer/explorer, task manager,
  control panel, chrome/google chrome, edge/microsoft edge, firefox,
  brave, spotify, vs code/vscode/visual studio code, word, excel,
  powerpoint, teams, discord, slack, steam, obs.
  Any other Windows App-Paths name also works via fallback.

SITES: youtube, google, gmail, github, whatsapp (web.whatsapp.com),
  maps/google maps, stack overflow, reddit, chatgpt, netflix,
  leetcode (problemset), twitter/x, instagram, linkedin.

Phonetic fixes: "you tube/utube/u tube"->youtube,
  "note pad/notpad"->notepad, "calc later"->calculator,
  "crome/chome"->chrome, "spotif y"->spotify, "git hub"->github.

  * "Open [app/site]" -> opens app or site.
  * "open example.com" -> opens https://example.com.

10. VISION CLICK & TYPE ON SCREEN (skills/automation.py + core/screen.py)
-------------------------------------------------------------
Vision-first patterns win over blind click/type. Needs grounding
model (cloud-backed; clear error without GEMINI_API_KEY). DPI-aware.
  * Click: "click [element]" / "click on [element]" /
    "click onto [element]" / "tap [element]" (+ please/the/my)
    e.g. "click on the Submit button", "click the search bar",
    "tap the X icon"
    -> grounds box [ymin,xmin,ymax,xmax], clicks center.
  * Type into: "type [text] in/into/inside/on [element]" /
    "write [text] in/into [element]" / "enter [text] into [element]" /
    "put [text] into [element]"
    e.g. "type hello into the search bar",
    "enter admin into the username field"
    -> clicks element, types text.
  * Focus search: "go to [the|my] search [bar|box|field]" /
    "focus [on] search [bar]" / "move to search" / "get to search"
    e.g. "go to the search bar" -> clicks search field, says ready.

-------------------------------------------------------------
11. MOUSE & KEYBOARD DIRECT (skills/automation.py, pyautogui)
-------------------------------------------------------------
  * Move: "move mouse up/down/left/right [by N]" / "mouse up/down/left/right"
    e.g. "move mouse right by 200" (default 100px, FAILSAFE=False)
  * Blind clicks at cursor: "click" / "double click" / "right click"
  * Press: "press [key]" / "hit [key]" where key =
    enter/return, escape/esc, space, tab, backspace, delete,
    up/down/left/right. e.g. "press enter", "hit escape"
  * Dictate: "type [text]" / "write [text]" e.g. "type hello world"
    -> paste via clipboard (pyperclip + ctrl+v).
    Note: "type X into Y" routes to vision-type (Sec.10) instead.

12. AI GENERATE & TYPE (skills/automation.py + core/llm.py)
-------------------------------------------------------------
Pattern: generate and type | draft and type |
  write a[n] email|file|letter|paragraph|essay|story|script|code|
  message|poem about | write about + <topic>
  * "Write an essay about [topic]" / "Write a paragraph about [topic]" /
    "Write an email about [topic]" / "Write a story/script/code about X" /
    "Generate and type [topic]" / "Draft and type [topic]"
    e.g. "write an essay about photosynthesis"
    -> says "Drafting that for you now", LLM writes it, pastes at cursor.

-------------------------------------------------------------
13. CLIPBOARD (skills/clipboard.py, pyperclip)
-------------------------------------------------------------
  * "Read my clipboard" -> speaks text (200-char cap + "...").
  * "Save my clipboard" / "Save my clipboard to notes"
    -> appends "[timestamp] Clipboard: <text>" to local.txt.

  * "Take a screenshot" / "Grab a screenshot" / "Grab the screenshot"
    -> ~/Pictures/Zia/Zia_YYYYMMDD_HHMMSS.png (Pillow ImageGrab).
       AgentNova `take_screenshot` tool variant -> %TEMP%/zia_screenshots/.
  * "what is on my screen" / "read my screen" / "analyze my screen" /
    "what am i looking at" + optional question
    e.g. "what is on my screen?", "read my screen and summarize this error"
    -> screenshots + vision LLM (Moondream/Gemini) speaks description.

-------------------------------------------------------------
14. NOTES & MEMORY (skills/notes.py + core/memory.py + core/nlp.py)
-------------------------------------------------------------
  * Take note: "take a note that [note]" / "remind me to [note]" /
    "note down [note]" / "remember that [note]" / "remember [note]"
    e.g. "take a note that meeting at 5pm",
    "remember my favorite color is blue", "remind me to call mom"
    -> long-term vector memory (SQLite + embeddings). Says "Note saved."
  * Implicit recall (no regex, NLP RAG in Zia.py):
    "What is my favorite color?" / "What is my dog's name?" /
    "What was that command?"
    -> spaCy entities -> vector DB -> injected context -> LLM answers.
    Short-term = last 5 turns; auto-consolidated on sleep.

20. HYBRID ARCHITECTURE (core/llm.py, automatic, no switch)
-------------------------------------------------------------
Cloud cascade Groq -> Gemini Flash -> OpenRouter; offline fallback
to local Ollama llama3.2. Vision via Moondream local / Gemini cloud.
STT Google Speech API (optional Ollama STT if USE_AGENTSDK_STT=True).
TTS local Piper (en_GB-alan-medium) + en-GB-RyanNeural, echo-cancelled
(mute_mic + tts_active) so Zia ignores herself. EffGen PromptOptimizer
compresses SIMPLE prompts when USE_EFFGEN=True.

-------------------------------------------------------------
21. BRAIN ROUTER (core/brain.py: SIMPLE vs TOOL vs MULTI_STEP)
-------------------------------------------------------------
Heuristics: MULTI_STEP = search|find|read|summarize|research|look up|
  navigate. TOOL = weather|calculate|math. Else LLM classifies.
  * SIMPLE: greetings, facts, memory recall -> generate_chat (5-turn
    ctx + NLP entities), spoken directly.
    e.g. "hello", "who is Alan Turing?", "what is my favorite color?"
  * TOOL/MULTI_STEP -> AgentNova executor (Sec.22) with convo memory.
  * Dangerous confirm (AGENTNOVA_CONFIRM_DANGEROUS=True): text with
    delete|remove|rm |format |kill -> "That sounds dangerous... say
    'proceed'..." Say "proceed/yes" to run, "cancel/no/stop/abort"
    to cancel ("Operation cancelled.").

-------------------------------------------------------------
22. AGENTNOVA COMPLEX AUTONOMY (core/executor.py + core/tools.py)
-------------------------------------------------------------
Unmatched speech with TOOL/MULTI_STEP goes here. agentkthx loop with
tools until done or AGENTNOVA_TIMEOUT_SEC (120s). Full FS
(C:\ D:\ E:\ F:\ /). Speak naturally, no rigid syntax.
Builtin subset: shell (PowerShell), read_file, write_file,
  list_directory, web-search (DDGS x3).
Custom: fetch_webpage(url) Playwright headless 15s, body text 10k cap;
  take_screenshot() to %TEMP%/zia_screenshots/;
  minimize_window(title) / maximize_window(title);
  press_keys(keys) comma list: volumemute, volumeup, volumedown,
  playpause, win, enter, ctrl,c etc.;
  click_on_screen(desc) / type_on_screen(desc, text) vision grounding;
  calculate(expr) safe AST (+ - * / ** xor neg);
  search_web(query) DDGS Title/Snippet/Link x3;
  read_file(path) / write_file(path, content, auto-opens on Win) /
  list_directory(path, auto-opens on Win).
  e.g. "Search Wikipedia for quantum mechanics and summarize it",
  "Research latest NVidia stock price", "Find my resume PDF and
  summarize skills", "List files in D:\Programming",
  "Minimize all chrome windows and mute volume",
  "Calculate 45 times 18 plus 7".

-------------------------------------------------------------
23. PROACTIVE MONITORING (core/proactive.py, auto, ~10s loop)
-------------------------------------------------------------
No command needed. RAM >90pct (5-min cooldown): "Sir, system memory
is critically high at N percent. Should I close background
processes?" CPU >95pct: "Sir, CPU usage has spiked to N percent."
Waits while user_is_speaking.

-------------------------------------------------------------
24. PENDING YES/NO CONFIRMATIONS (core/pending.py interceptor)
-------------------------------------------------------------
Skills asking follow-ups ("Should I send it?") consume your NEXT
utterance first, even during TTS, so "yes/proceed" is not misread
as a new command. Unrelated speech still routes normally.
