=============================================================
             ZIA ASSISTANT - COMPREHENSIVE COMMAND GUIDE
=============================================================
This file contains the complete list of commands, capabilities, and features built into Zia. 

-------------------------------------------------------------
1. ZEN MODE (Lightning Speed & Cloud APIs)
-------------------------------------------------------------
Zen Mode forces Zia to use a cascading chain of lightning-fast cloud APIs (Groq -> Gemini Flash -> OpenRouter) rather than local models, prioritizing extreme speed and accuracy for complex tasks.
• "Go zen"
• "Start zen mode"
• "Switch"
• "Initialize zen mode"
• "Activate zen mode"
• "Go to zen mode"
*Note: Zia will automatically fall back to normal mode (Local) if networks drop or limits are reached.*

-------------------------------------------------------------
2. CORE SYSTEM & ASSISTANT CONTROL
-------------------------------------------------------------
• "Shut down Zia" / "Exit Zia" / "Quit Zia" -> Shuts down the assistant entirely.
• "Go to sleep" / "Sleep Zia" -> Puts Zia into standby mode (waiting for wake word) and consolidates memories.
• "Abort task" / "Stop what you are doing" / "Cancel task" -> Instantly cancels any stuck LLM process or background task.
• "Who are you" / "What can you do" / "List commands" / "Help" -> Zia introduces herself and explains her capabilities.

-------------------------------------------------------------
3. DATE, TIME, & WEATHER
-------------------------------------------------------------
• "What's the time" / "What time is it" / "Time" -> Tells the current local time.
• "What's the date" / "What day is it" / "Date" -> Tells the current date and day of the week.
• "What is the weather" / "Weather today" / "How is the weather" -> Fetches and reads the current local weather.

-------------------------------------------------------------
4. WORKSPACES & ROUTINES
-------------------------------------------------------------
Zia can instantly set up your entire coding environment (opening VS Code, specific folders, splitting terminals, opening browser tabs, etc.) based on predefined routines.
• "Start DSA work" / "Open data structures" -> Sets up Leetcode and coding workspace.
• "Start development" / "Open web dev" -> Sets up general development environment.
• "Start Zia work" / "Open Zia" -> Opens the Zia project directory and environments.
• "Start hackathon work" -> Sets up a rapid-prototyping workspace.

-------------------------------------------------------------
5. APP & WINDOW MANAGEMENT
-------------------------------------------------------------
• "Open [app name]" / "Launch [app]" / "Start [app]" -> Opens any installed application.
• "Close [app name]" / "Quit [app]" -> Force closes an application.
• "Snap [app] to the left" -> Snaps the specified window to the left half of the screen.
• "Snap [app] to the right" -> Snaps the specified window to the right half of the screen.
• "Maximize [app]" -> Maximizes and brings the specified window to the front.

-------------------------------------------------------------
6. MEDIA & AUDIO CONTROLS
-------------------------------------------------------------
• "Volume up" / "Louder" / "Turn it up" -> Increases system volume.
• "Volume down" / "Quieter" / "Turn it down" -> Decreases system volume.
• "Mute" / "Silence" / "Shut up" -> Mutes the system volume.
• "Play" / "Pause" / "Resume" -> Controls media playback.
• "Next" / "Skip" -> Skips to the next track/video.
• "Previous" / "Go back" -> Goes to the previous track/video.
• "Stop" -> Stops media playback.

-------------------------------------------------------------
7. WEB SEARCH & BROWSING
-------------------------------------------------------------
• "Google [query]" / "Open a google search for [query]" -> Opens browser and searches Google.
• "Play [query] on youtube" / "Find [query] on youtube" -> Opens YouTube and searches the query.

-------------------------------------------------------------
-------------------------------------------------------------
8. VISION & SCREENSHOTS & AUTONOMOUS COMPUTER USE
-------------------------------------------------------------
• "Take a screenshot" / "Grab a screenshot" -> Captures the screen and saves it to a temp folder.
• "What is on my screen?" / "Analyze my screen" -> Takes a screenshot and passes it to the Moondream Vision LLM, answering questions about what you are currently looking at.
• "Click on the Submit button" (Zia takes a screenshot, finds the bounding box via Gemini, and clicks it)
• "Type 'hello' into the search bar" (Zia finds the search bar, clicks it, and types)

-------------------------------------------------------------
9. CONFIRMED MESSAGING (VOICE TEXTING) not working now, will be fixed soon.
-------------------------------------------------------------
• "Message Ayush saying I'll be late on WhatsApp"
• "Text Mom that I am coming home on Telegram"
• "Text Alex I will call you later on Instagram"
• "Send Sam hello on Discord"
  (Zia opens the selected web app, finds the chat, types the message, and asks "Should I send it?" before hitting Enter.)

-------------------------------------------------------------
9. MOUSE, KEYBOARD & AUTOMATION
-------------------------------------------------------------
• "Move mouse up/down/left/right by [amount]" -> Moves the cursor.
• "Click" / "Double click" / "Right click" -> Clicks the mouse.
• "Press [key]" -> Presses specific keys (Enter, Esc, Space, Tab, Backspace, Delete, Arrows).
• "Type [text]" -> Literally types the dictated text via keyboard automation.
• "Write an email/letter/paragraph about [topic]" -> Zia generates content using the LLM and automatically types it out into whatever window is currently focused.

-------------------------------------------------------------
10. CLIPBOARD MANAGEMENT
-------------------------------------------------------------
• "Read my clipboard" -> Reads the current text content of your clipboard out loud.
• "Save my clipboard (to notes)" -> Takes whatever text you copied and saves it into Zia's memory.

-------------------------------------------------------------
11. TIMERS
-------------------------------------------------------------
• "Set a timer for [X] hours [Y] minutes [Z] seconds" -> Starts a background countdown timer that will alert you when finished.

-------------------------------------------------------------
12. MEMORY & PROACTIVE INTELLIGENCE
-------------------------------------------------------------
• "Take a note that [note]" / "Remember [fact]" / "Remind me to [task]" -> Explicitly saves a memory/fact into Zia's local vector database.
• *Implicit Memory*: You can simply ask "What is my favorite color?" or "What was that command I copied earlier?". Zia uses NLP Entity Extraction to grab exact subjects, pulls relevant context from the RAG vector database, and dynamically injects it into the prompt.

-------------------------------------------------------------
13. AGENTNOVA (COMPLEX OS AUTONOMY)
-------------------------------------------------------------
If a command does not match any of the direct regex phrases above, Zia's "Brain" classifies it. If it is complex, she hands it off to AgentNova. AgentNova is an autonomous agent capable of utilizing OS tools to accomplish goals.
Examples of things you can ask AgentNova to do:
• "Delete the temporary files in my downloads folder."
• "Read the file on my desktop called notes.txt and summarize it."
• "Create a new text file on my desktop and write a python script for a calculator."
• "Search Wikipedia for Quantum Mechanics, read the article, and give me a summary."
• "Go to [url] and read the page to me."
*(AgentNova requires confirmation before running dangerous commands like delete/format).*

-------------------------------------------------------------
SYSTEM LOCK
-------------------------------------------------------------
• "Lock PC" / "Lock screen" -> Immediately locks your Windows workstation.
