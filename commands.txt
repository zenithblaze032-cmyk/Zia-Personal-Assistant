=============================================================
             ZIA ASSISTANT - COMPREHENSIVE COMMAND GUIDE
=============================================================
This file contains the complete list of commands, capabilities, and features built into Zia.

-------------------------------------------------------------
1. HYBRID ARCHITECTURE (Automatic Cloud & Local)
-------------------------------------------------------------
Zia automatically uses a cascading chain of lightning-fast cloud APIs (Groq -> Gemini Flash -> OpenRouter). If all APIs fail or you lose internet connection, she will automatically fall back to local LLMs. There are no manual switches needed.

-------------------------------------------------------------
2. CORE SYSTEM & ASSISTANT CONTROL
-------------------------------------------------------------
• "Shut down Zia" / "Exit Zia" / "Quit Zia" -> Shuts down the assistant entirely.
• "Go to sleep" / "Sleep Zia" -> Puts Zia into standby mode (waiting for wake word).
• "Wake up" / "Wake up Zia" -> Awakens Zia from sleep.
• "Abort task" / "Stop what you are doing" / "Cancel task" -> Instantly cancels any stuck process or background task.
• "Who are you" / "What can you do" / "List commands" / "Help" -> Zia introduces herself and capabilities.

-------------------------------------------------------------
3. DATE, TIME, & WEATHER
-------------------------------------------------------------
• "What's the time" / "What time is it" / "Time" -> Tells the current local time.
• "What's the date" / "What day is it" / "Date" -> Tells the current date.
• "What is the weather" / "Weather today" -> Fetches and reads current weather.

-------------------------------------------------------------
4. WORKSPACES & ROUTINES
-------------------------------------------------------------
• "Start DSA work" / "Open data structures" -> Sets up Leetcode and coding workspace.
• "Start development" / "Open web dev" -> Sets up general development environment.
• "Start Zia work" / "Open Zia" -> Opens the Zia project directory and environments.
• "Start hackathon work" -> Sets up a rapid-prototyping workspace.

-------------------------------------------------------------
5. APP & WINDOW MANAGEMENT
-------------------------------------------------------------
• "Open [app name]" / "Launch [app]" -> Opens any installed application.
• "Close [app name]" / "Quit [app]" -> Force closes an application.
• "Snap [app] to the left" -> Snaps window to the left half.
• "Snap [app] to the right" -> Snaps window to the right half.
• "Maximize [app]" -> Maximizes and focuses the window.

-------------------------------------------------------------
6. MEDIA & AUDIO CONTROLS
-------------------------------------------------------------
• "Volume up" / "Louder" -> Increases system volume.
• "Volume down" / "Quieter" -> Decreases system volume.
• "Mute" / "Silence" / "Shut up" -> Mutes the system volume.
• "Play" / "Pause" / "Resume" -> Controls media playback.
• "Next" / "Skip" -> Skips track.
• "Previous" / "Go back" -> Previous track.
• "Stop" -> Stops media playback.

-------------------------------------------------------------
7. WEB SEARCH & BROWSING
-------------------------------------------------------------
• "Google [query]" / "Search google for [query]" -> Opens browser and searches Google.
• "Play [query] on youtube" / "Find [query] on youtube" -> Opens YouTube and plays the exact video.
• "Search Wikipedia for [query] and summarize" -> Silently fetches HTML and reads summary.

-------------------------------------------------------------
8. VISION, SCREENSHOTS & AUTONOMY
-------------------------------------------------------------
• "Take a screenshot" / "Grab a screenshot" -> Captures and saves the screen.
• "What is on my screen?" / "Analyze my screen" -> Takes a screenshot and passes it to the Vision LLM to answer what you are looking at.
• "Click on [element]" -> Zia takes a screenshot, finds the bounding box via vision grounding, and clicks it.
• "Type [text] into [element]" -> Zia finds the element, clicks it, and types the text.

-------------------------------------------------------------
9. MOUSE & KEYBOARD
-------------------------------------------------------------
• "Move mouse up/down/left/right by [amount]" -> Moves cursor.
• "Click" / "Double click" / "Right click" -> Mouse clicks.
• "Press [key]" -> Presses specific keys (Enter, Esc, Space, etc).
• "Type [text]" -> Types the dictated text.
• "Write an essay/paragraph about [topic]" -> Zia generates content using the LLM and types it automatically.

-------------------------------------------------------------
10. CLIPBOARD & NOTES
-------------------------------------------------------------
• "Read my clipboard" -> Reads copied text.
• "Save my clipboard" -> Saves copied text into memory.
• "Take a note that [note]" / "Remember [fact]" -> Saves fact to vector DB.

-------------------------------------------------------------
11. TIMERS
-------------------------------------------------------------
• "Set a timer for [X] hours [Y] minutes [Z] seconds" -> Starts background countdown.

-------------------------------------------------------------
12. MEMORY & NLP RAG
-------------------------------------------------------------
• *Implicit Memory*: You can ask "What is my favorite color?" or "What was that command?". Zia uses NLP Entity Extraction to grab exact subjects and pull context from the local RAG vector database.

-------------------------------------------------------------
13. AGENTNOVA (COMPLEX OS AUTONOMY)
-------------------------------------------------------------
If a command does not match any regex phrases, Zia's Brain classifies it. If complex, AgentNova iteratively uses OS tools to solve the goal.
