Zia Voice Commands Quick Reference

SYSTEM CONTROLS
- "What's the time?" / "Time"
- "What's the date?" / "Date"
- "Volume up" / "Louder" (AgentNova)
- "Volume down" / "Quieter" (AgentNova)
- "Mute my volume" / "Shut up" (AgentNova)
- "Take a screenshot" / "Grab a screenshot" (AgentNova)
- "What is on my screen?" / "Analyze my screen" (Uses Moondream Vision)
- "Lock pc" / "Lock screen"
- "Who are you?" / "Help" / "List commands"
- "Abort task" / "Stop what you are doing" (Watchdog: Instantly cancels any stuck LLM process)

MEDIA CONTROLS
- "Play" / "Pause" / "Resume" (AgentNova)
- "Next" / "Skip"
- "Previous" / "Go back"
- "Stop"

WORKSPACES & ROUTINES
- "Start DSA work" / "Open data structures"
- "Start web dev work" / "Open development"
- "Start Zia work"
- "Start hackathon work"

WEB SEARCH & BROWSING
- "Google [query]" / "Open a google search for [query]"
- "Play [query] on youtube"
- "Search Wikipedia for [topic], read the article, and summarize it" (AgentNova)
- "Go to [url] and read it to me" (AgentNova)

WEATHER & TIMERS
- "What is the weather?" / "Weather today"
- "Set a timer for [X] hours [Y] minutes [Z] seconds"

WINDOW MANAGEMENT (AgentNova)
- "Snap [app] to the left"
- "Snap [app] to the right"
- "Maximize [app window]"
- "Minimize [app window]"

CLIPBOARD & AUTOMATION
- "Read my clipboard"
- "Save my clipboard"
- "Move mouse up/down/left/right by [X]"
- "Click" / "Double click" / "Right click"
- "Write an email/letter/paragraph about [topic]" (Generates text and types it out automatically)

MEMORY & PROACTIVE INTELLIGENCE
- "Take a note that [note]" / "Remember [fact]" -> Saves explicitly to local vector database.
- Ask questions about facts, e.g., "What is my favorite color?" -> Uses instant NLP Entity Extraction (spaCy) to grab exact subjects and route to LLM with injected RAG memory.
- Memory works continuously; you do not need to say "go to sleep" to pull recent facts into context.

COMPLEX TASKS (AgentNova)
- "Delete the temp files" -> Executes shell commands (asks for confirmation first).
- "Read the file on my desktop and summarize it" -> Uses AgentNova's OS tools.
- "Create a new text file on my desktop called 'todo' and write 'buy milk'" -> Uses AgentNova file tools.

PROGRAM CONTROL
- "Shut down Zia" -> Exits program.
- "Go to sleep" -> Enters standby mode (waiting for wake word) and triggers memory consolidation.
